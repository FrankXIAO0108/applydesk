# 路线图

## v0.1：可验证的记录与决策 MVP

- [x] 看板、持久化、公司范围、候选筛选。
- [x] 人工确认队列、官网原文、异常留痕。
- [x] 飞书同步与代理数据入口。
- [x] 本地启动、空数据库、隐私导出检查、基础测试。

## 下一步：让一次真实巡检可重复运行

- [ ] 一个官网的独立只读适配器与合成测试夹具。
- [ ] 登录、分页、记录标识和失败恢复的明确契约。
- [ ] 首次观察和后续变化的完整审计证据。

## 再下一步：调度与可运维性

- [x] Codex 桌面定时任务执行协议、北京时间周期、重复触发控制。
- [x] 自定义筛选、公司管理、每周／两周检索周期。
- [x] 运行历史、服务端核验、超时与部分完成记录。
- [ ] 不依赖桌面代理的独立采集器与云端调度。
- [ ] 公开部署所需的身份认证和秘密管理。

## 最后：受控投递

- [ ] 多版本简历映射和缺失字段收集。
- [ ] 逐岗确认、提交前核验、提交后回执和幂等保护。
- [ ] 验证失败时转人工，保存中间状态。

不以“有按钮”“保存了设置”或“模型说成功”作为完成标准。
